# Anatomiapeli V7 – GitHub Pages -pilotti

15 kysymyksen julkaisuvalmis web-pilotti. V7 korjaa nuolten koordinaatiston: kuva ja A-nuoli käyttävät samaa alkuperäistä kuvan koordinaatistoa, joten merkintä ei siirry eri näyttökoossa.

## Julkaisu GitHub Pagesiin
1. Luo GitHubissa uusi repository, esim. `anatomiapeli`.
2. Pura ZIP ja lataa **kansion sisältö** repositoryn juureen (index.html pitää näkyä heti repossa).
3. Avaa Settings → Pages.
4. Source: Deploy from a branch → `main` → `/(root)` → Save.
5. GitHub näyttää hetken kuluttua sivun HTTPS-osoitteen.

## Pilotin kuvamateriaali
- Kallo: Human skull nolables, LadyofHats/Jcwf, public domain, Wikimedia Commons.
- Alaraaja: Human leg bones labeled, Jecowa/LadyofHats, public domain, Wikimedia Commons.
- Yläraaja ja lapaluu ovat vielä paikallisia pilotin kaavioita ja ne vaihdetaan lopullisessa kuvapankissa yksityiskohtaisempiin avoimiin kuviin.

Kallo- ja alaraajakuvat ladataan tässä väliversiossa Wikimedia Commonsista. Seuraava kuvapankkivaihe tallentaa hyväksytyt kuvat `assets/images/`-kansioon ennen lopullista 244 rakenteen versiota.
