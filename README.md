# Anatomiapeli V8 – luuston laadunvarmistus

V8:n ensimmäinen kehitysversio. V7:n toimiva pelimoottori on korvattu siistillä, responsiivisella rungolla, jossa nuolimerkinnät käyttävät kuvan omaa koordinaatistoa.

## Kalibrointitila
Avaa sivu lisäämällä osoitteen loppuun `?calibrate=1`. Napauta/klikkaa anatomista kohdetta: kuvan alkuperäiset x,y-koordinaatit näytetään ja kopioidaan leikepöydälle.

## Sisältö tässä paketissa
Ensimmäinen QA-erä sisältää 5 kallokysymystä. Tarkoitus on hyväksyä kuvat ja nuolten osumat ennen koko luusto-osion kasvattamista.

## Julkaisu
Korvaa GitHub-repositorion juuren `index.html`, `app.js`, `questions.js`, `styles.css` ja `README.md` näillä tiedostoilla. GitHub Pages julkaisee main-haaran juuren automaattisesti.
