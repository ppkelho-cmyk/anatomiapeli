# Anatomiapeli V8 – QA5.4

QA1–QA4 lukittu: **30 hyväksyttyä kysymystä**. QA5.4:ssa on **43 kysymystä**.

## QA5.4 – korjauskierros

- sääriluu ja pohjeluu: yhteinen selkeä CC0-valokuva, nuolet suoraan luun runkoon
- ulkokehräs: sama neutraali tibia–fibula-kuva ilman punaista tehostusväriä
- sisäkehräs: nuoli siirretty varsinaiselle mediaaliselle kehräkselle
- iso ja pieni sarvennoinen: nuolet siirretty anatomisille prominensseille
- polvilumpio: vaihdettu selkeään patellan etupinnan valokuvaan
- häpyluun ja lonkkamaljan QA5.2-korjaukset säilytetty

QA1–QA4:n lukittuihin kysymyksiin ei ole tehty muutoksia.


## QA5.4 – orientaatiokierros

- polvilumpio siirretty polvinivelen kokonaiskuvaan
- sääriluu, pohjeluu, sisäkehräs ja ulkokehräs käyttävät jalan + jalkaterän anteriorista kokonaiskuvaa
- nivelhaarakkeet siirretty lannenikaman superioriseen lähikuvaan, jotta ne erottuvat poikkihaarakkeista
- QA1–QA4:n muut kysymykset pidetty ennallaan
