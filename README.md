# Anatomiapeli V8 – QA2

V8:n toinen laadunvarmistuserä. Mukana ovat QA1:n viisi kallokysymystä sekä hartian ja yläraajan perusrakenteet opiskelulistan mukaisesti.

## QA2:n tarkoitus
- tarkistaa uuden avoimen anatomisen yläraajakuvan toiminta Macilla ja iPhonella
- tarkistaa A-nuolten osuminen rakenteisiin
- säilyttää kalibrointitila (`?calibrate=1`) nuolten hienosäätöä varten
- hyväksyä vain toimivat kysymykset ennen seuraavaa luustoerää
