## QA11.2 fix 7
QA11.2:n kuva rajattu ylävartaloon (ylävatsasta päähän), jotta aortan kaaren haarat näkyvät suurempina. Korostukset muutettu ohuemmiksi, paikallisiksi viivakorostuksiksi. QA11.2 pysyy review-tilassa: 119 locked + 3 review = 122 kysymystä.


## QA11.2 fix 8

Nykyinen ylävartalorajaus säilyy, ja nuolenkärjet osoittavat paikallisesti käden ja pään valtimorunkoon, yhteiseen pään-/kaulavaltimoon ja solisvaltimoon. Kysymysmuoto on nyt ‘Mikä valtimo on merkitty A-nuolella?’. QA11.2 pysyy review-tilassa: 119 locked + 3 review = 122 kysymystä.

## QA11.2 fix 9
QA11.2:n A-nuolet kalibroitu uudelleen fix 8:n peliscreenshotien perusteella. Kuvan rajaus, kysymystekstit ja muu ulkoasu pidetty ennallaan. QA11.2 pysyy review-tilassa: 119 locked + 3 review = 122.

## QA11.2 fix 10
QA11.2:n A-nuolille tehty viimeinen hienokalibrointi: käden ja pään valtimorungon nuolenkärki siirretty alemmas itse lyhyen rungon keskelle ja solisvaltimon kohdistusta tarkennettu suonen keskelle. Yhteisen pään-/kaulavaltimon nuoli sekä kuvan rajaus, kysymystekstit ja muu ulkoasu pidetty ennallaan. QA11.2 pysyy review-tilassa: 119 locked + 3 review = 122.


## QA11.2 fix 11
QA11.2:n käden ja pään valtimorungon A-nuolen kärkipistettä hienosäädetty fix 10:n peliscreenshotin perusteella hieman ylemmäs ja vasemmalle itse lyhyen valtimorungon keskelle. Solisvaltimon ja yhteisen pään-/kaulavaltimon hyväksyttyihin nuoliin ei tehty muutoksia. QA11.2 pysyy review-tilassa: 119 locked + 3 review = 122.

Neljän yläraajan valtimon kuva rajattu aiempaa tiukemmin olkapään–käden alueelle ja nuolenkärjet kalibroitu anatomisesti selkeämpiin kohtiin: kainalovaltimo kainaloon, olkavarsivaltimo olkavarren pääsuoneen, kyynärvaltimo kyynärvarren ulnaaripuolelle ja värttinävaltimo radiaalipuolelle.
