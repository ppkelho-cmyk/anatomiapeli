# Anatomiapeli V8 – QA2.1

QA2.1 on yläraajan nuolikalibroinnin korjausversio.

Korjattu käyttäjän QA-testin perusteella:
- solisluun kohdepiste siirretty selvästi solisluun varrelle
- värttinäluun kohdepiste siirretty lateraalisemmaksi luun rungon päälle
- kyynärluun kohdepiste siirretty mediaalisemmaksi luun rungon päälle

Muut QA2-kysymykset on jätetty ennalleen. Kalibrointitila säilyy osoitteen parametrilla `?calibrate=1`.
