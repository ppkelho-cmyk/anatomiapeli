# Anatomiapeli V8 — QA8.1 korppilisäkkeen tarkennus

**QA1–QA7.1 lukittu: 48 kysymystä.**

QA8.1:n tarkistuksessa hyväksyttiin:

- olkalisäke → `locked`
- lapaluun harju → `locked`

Korppilisäkkeen A-nuolen kärkipistettä siirrettiin hieman ylemmäs, jotta se osoittaa selvemmin olkalisäkkeen/lapaluun harjun takana näkyvään korppilisäkkeeseen. Korppilisäke jää vielä `review`-tilaan lopputarkistusta varten.

Yhteensä 51 kysymystä: **50 locked + 1 review**.

Avaa **QA-tarkastus → Näytä vain review-kysymykset**, jolloin näkyviin tulee vain korppilisäke.
